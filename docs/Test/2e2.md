# Pruebas End-to-End (E2E) - SkinCancerApp

## Herramienta

* Playwright

---

# Ejecutar todas las pruebas

```bash
npx playwright test
```

---

# Ejecutar una prueba específica

```bash
npx playwright test frontend-tests/login.spec.js
```

---

# Generar el reporte HTML

```bash
npx playwright test --reporter=html
```

---

# Abrir el reporte

```bash
npx playwright show-report
```

---

# Estructura del proyecto

```text
├── frontend-tests/
│   ├── login.spec.js
│   ├── registro.spec.js
│   ├── analisis.spec.js
│   ├── historial.spec.js
│   └── logout.spec.js
│
├── playwright.config.js
├── playwright-report/
├── test-results/
└── package.json
```

---

# Casos de prueba

* Inicio de sesión.
* Registro de usuario.
* Análisis de imagen.
* Consulta del historial.
* Cierre de sesión.

frontend/playwright-report/

## Evidencias

```text
frontend/test-results/
```

En estas carpetas se almacenan automáticamente el reporte HTML, capturas de pantalla, videos y archivos de traza generados durante la ejecución de las pruebas.
